# Atividade — Tailwind CSS + React

Projeto acadêmico desenvolvido para praticar a criação de interfaces utilizando React e Tailwind CSS.

## Tecnologias utilizadas

- React
- JavaScript
- Tailwind CSS
- Vite
- HTML e JSX
- Git e GitHub

## Objetivo

Desenvolver componentes reutilizáveis e interfaces responsivas, aplicando conceitos de componentização, props, JSX, Flexbox, Grid e estilização com Tailwind CSS.

## Exercícios React + Tailwind

### 01 — Button System

Sistema de botões reutilizáveis com diferentes estilos e estados visuais.

### 02 — Badge + Avatar

Componentes para exibir indicadores de status e imagens de perfil.

### 03 — Profile Card

Cartões de perfil utilizando componentes reutilizáveis e props.

### 04 — Product Card

Cartões de produtos com imagem, descrição, preço e botão.

### 05 — Login Form

Formulário de login com campos de e-mail, senha e opções de acesso.

### 06 — KPI Card

Cartões para apresentar indicadores e variações de desempenho.

### 07 — Pricing Card

Cartões de planos e preços com funcionalidades e destaque para o plano principal.

### 08 — Alert / Notification

Componentes de alertas de sucesso, erro, aviso e informação.

### 09 — Responsive Navbar

Barra de navegação responsiva com menu adaptado para dispositivos móveis.

### 10 — Mini Dashboard

Painel administrativo responsivo com indicadores, projetos e atividades recentes.

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/wanessags/Tailwind-CSS-React-.git
```

2. Acesse a pasta do projeto.

3. Instale as dependências:

```bash
npm install
```

4. Inicie o servidor:

```bash
npm run dev
```

5. Abra no navegador o endereço informado pelo Vite.
